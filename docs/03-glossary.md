# Glossary

## Controller

Central decision-making device.

## Machine Node

ESP installed on a woodworking machine.

## Gate Node

ESP controlling one blast gate.

## Route

List of gate UIDs required for extraction.

## Unit

Logical function hosted by a Physical Device, such as a Machine, Gate, or
Collector. A Unit has its own type and capabilities within the Controller's
model.

## Event

Immutable fact about something that has happened in the system. Events may be
consumed by multiple subscribers and do not request behavior.

## Command

Request for behavior sent to one recipient. Commands are confirmed by later
Events rather than modifying Controller state directly.

## State

The current condition of a device, Unit, service, or workflow within its
defined state machine.

## Extraction Demand

Request generated by a machine.

## UID

Immutable device identity.

Example:

```
GATE-84F3EB12A91C
```

## Friendly Name

Human-readable device name.

Example:

```
Main Trunk Gate
```

## Capability

Function supported by a device.

Examples:

- Position feedback
- Timed gate
- Current sensor

## Run-on Timer

Time between last extraction demand disappearing and collector shutdown.
