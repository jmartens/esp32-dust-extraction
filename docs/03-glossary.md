# Glossary

## Controller

Central decision-making device.

## Machine Node

ESP installed on a woodworking machine.

## Gate Node

ESP controlling one blast gate.

## Route

List of gate UIDs required for extraction.

## Extraction Demand

Request generated by a machine.

## UID

Immutable device identity.

Example:

```
GATE-84F3EB12A91C
```

## Friendly Name

Human-readable device name.

Example:

```
Main Trunk Gate
```

## Capability

Function supported by a device.

Examples:

- Position feedback
- Timed gate
- Current sensor

## Run-on Timer

Time between last extraction demand disappearing and collector shutdown.
